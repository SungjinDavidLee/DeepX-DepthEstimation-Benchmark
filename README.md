# On-Device Vision Model Benchmark

온디바이스 가속기에서 비전 추론 모델의 지연, 처리량, 전력을 측정한 기록이다.

측정 대상은 Raspberry Pi 5에 장착한 DEEPX DX-M1 NPU와 NVIDIA Jetson AGX Xavier이며, 깊이 추정·객체 검출·인스턴스 분할·클래스 무관 분할 네 가지 작업을 다룬다.

측정 절차와 원본 수치를 남기는 것이 목적이다. 플랫폼 간 비교는 조건이 일치하는 항목에 한해 제시한다.

## 2. 측정 결과

### 2-1. Raspberry Pi 5 + DX-M1

`dxbenchmark` NPU 태스크 프로파일 기준. 값은 평균이다.

| 작업 | 모델 | 입력 | NPU 추론 | H2D | D2H | 출력 형식 변환 | CPU 태스크 |
|---|---|---|---|---|---|---|---|
| 객체 검출 | yolov8-n | 640×640 | 3.83 ms | 3.15 ms | 7.97 ms | 11.75 ms | 20.41 ms |
| 인스턴스 분할 | yolov8-n-seg | 640×640 | 5.26 ms | 3.40 ms | 13.84 ms | 20.19 ms | 22.33 ms |
| 깊이 추정 | DAv2 ViT-S | 224×224 | 17.99 ms | 1.01 ms | 2.66 ms | 4.22 ms | 47.27 ms |
| 깊이 추정 | DAv2 ViT-B | 224×224 | 46.66 ms | 1.02 ms | 5.16 ms | 9.35 ms | 92.12 ms |
| 클래스 무관 분할 | FastSAM-s | 1024×1024 | 22.39 ms | 7.13 ms | 23.61 ms | 47.57 ms | 51.60 ms |

깊이 추정 모델은 CPU 전처리 태스크가 별도로 존재하며 0.31 ms를 차지한다. 나머지 세 모델은 NPU에서 시작한다.

### 2-2. Jetson AGX Xavier

`trtexec` 기준. 지연은 평균이며 p99를 함께 표기했다.

| 작업 | 모델 | 입력 | GPU 연산 | p99 | 처리량 | 전류 | 전력 | FPS/W |
|---|---|---|---|---|---|---|---|---|
| 객체 검출 | yolov8n | 640×640 | 9.28 ms | 9.32 ms | 107.75 qps | 693.9 mA | 13.46 W | 8.00 |
| 인스턴스 분할 | yolov8n-seg | 640×640 | 10.72 ms | 10.79 ms | 93.19 qps | 696.5 mA | 13.51 W | 6.90 |
| 깊이 추정 | DAv2 ViT-S | 224×224 | 13.90 ms | 14.05 ms | 71.94 qps | 678.5 mA | 13.16 W | 5.47 |
| 깊이 추정 | DAv2 ViT-B | 224×224 | 31.87 ms | 32.07 ms | 31.38 qps | 733.3 mA | 14.23 W | 2.21 |
| 클래스 무관 분할 | FastSam-S | 640×640 | 19.74 ms | 19.77 ms | 50.66 qps | 705.3 mA | 13.68 W | 3.70 |

유휴 상태는 424 mA, 8.23 W다. 전력은 INA3221 두 채널의 전류 합에 입력 전압 19.4 V를 곱한 값이며, 시스템 전체 소비를 나타낸다.

### 2-3. 참고 — 해상도에 따른 변화 (Xavier)

동일 모델에서 입력 해상도만 변경한 경우다.

| 모델 | 입력 | GPU 연산 | 처리량 |
|---|---|---|---|
| DAv2 ViT-S | 224×224 | 13.90 ms | 71.94 qps |
| DAv2 ViT-S | 518×518 | 83.63 ms | 11.92 qps |

픽셀 수는 5.35배, 연산 시간은 6.01배 증가했다.

## 3. 플랫폼 간 대조

가속기 연산 구간만 대조한다. DX-M1은 `Inference`, Xavier는 `GPU Compute Time`이다. 두 값 모두 데이터 전송과 CPU 처리를 포함하지 않는다.

### 3-1. 조건이 일치하는 항목

모델 계열, 입력 해상도, 배치 크기가 같은 경우다.

| 작업 | 입력 | DX-M1 (INT8) | Xavier (FP16) | 비 |
|---|---|---|---|---|
| 객체 검출 | 640×640 | 3.83 ms | 9.28 ms | DX-M1 2.42× |
| 인스턴스 분할 | 640×640 | 5.26 ms | 10.72 ms | DX-M1 2.04× |
| 깊이 추정 ViT-S | 224×224 | 17.99 ms | 13.90 ms | Xavier 1.29× |
| 깊이 추정 ViT-B | 224×224 | 46.66 ms | 31.87 ms | Xavier 1.46× |

연산 정밀도가 다르다. DX-M1은 INT8 고정이고 Xavier는 FP16이다. 이 표는 각 플랫폼의 기본 배포 설정에서의 결과이며, 동일 정밀도 조건의 비교가 아니다.

### 3-2. 조건이 일치하지 않는 항목

| 작업 | DX-M1 | Xavier |
|---|---|---|
| 클래스 무관 분할 | FastSAM-s, 1024×1024, 22.39 ms | FastSam-S, 640×640, 19.74 ms |

입력 픽셀 수가 2.56배 차이나므로 **두 값을 직접 비교할 수 없다.** 각각의 조건에서의 기록으로만 사용한다.

### 3-3. 전력

Xavier만 측정했다. Raspberry Pi 5는 내장 전력 센서가 없고 외부 계측 장비를 확보하지 못했다.

## 4. 관찰

### 4-1. 작업 유형에 따라 우열이 갈린다

Convolution 위주의 검출·분할 모델에서는 DX-M1이 2배 이상 빠르고, Transformer 기반 깊이 추정 모델에서는 Xavier가 1.3~1.5배 빠르다.

**가설:** DX-M1의 연산 유닛이 convolution에 최적화되어 있고, ViT 계열의 attention 연산은 메모리 대역폭 제약을 더 크게 받는다. 이번 측정만으로는 확정할 수 없으며, 연산자 단위 프로파일링이 필요하다.

### 4-2. DX-M1에서는 추론 외 구간이 지배적이다

NPU 태스크 전체에서 순수 추론이 차지하는 비중이다.

| 모델 | 추론 | NPU 태스크 총계 | 비중 |
|---|---|---|---|
| yolov8-n | 3.83 ms | 27.48 ms | 14% |
| yolov8-n-seg | 5.26 ms | 43.77 ms | 12% |
| FastSAM-s | 22.39 ms | 102.89 ms | 22% |
| DAv2 ViT-S | 17.99 ms | 27.40 ms | 66% |
| DAv2 ViT-B | 46.66 ms | 63.94 ms | 73% |

검출·분할 모델에서 D2H 전송과 출력 형식 변환이 추론 시간을 크게 상회한다. yolov8-n-seg의 경우 NPU 출력이 10개 텐서 합계 9.19 MB이며, PCIe Gen3 x1 링크에서 D2H에만 13.84 ms가 소요된다.

깊이 추정 모델은 출력 텐서가 작아 이 비중이 낮은 대신, CPU 후처리 태스크가 추론보다 크다(ViT-S 47.27 ms, ViT-B 92.12 ms).

### 4-3. Xavier의 소비 전력은 모델과 무관하게 일정하다

부하 시 전력이 13.16~14.23 W 범위에 머문다. 모델 규모에 따른 차이는 8% 이내다. GPU가 포화 상태로 동작할 때의 전력이 유사하며, 작업량 차이는 소요 시간으로 나타난다.

결과적으로 전력 효율(FPS/W)은 처리량에 거의 비례한다.

### 4-4. NPU 코어 간 부하가 균등하지 않다

DX-M1의 코어별 추론 시간이다.

| 모델 | Core 0 | Core 1 | Core 2 |
|---|---|---|---|
| yolov8-n | 3.81 ms | 5.76 ms | 5.17 ms |
| DAv2 ViT-S | 17.96 ms | 21.29 ms | 21.45 ms |
| DAv2 ViT-B | 46.55 ms | 61.74 ms | 61.25 ms |

Core 0이 가장 짧고 나머지 두 코어가 더 길다. 배치 크기 1에서 코어 간 부하 분배가 균등하지 않은 것으로 보이나, 원인은 확인하지 못했다.

### 4-5. 지연 분포

Xavier는 모든 모델에서 p99가 평균의 1.01배 이내다. `dxbenchmark`는 min/max/평균/CoV를 제공하며 백분위수를 제공하지 않아, DX-M1의 지연 분포는 동일한 형태로 확인할 수 없었다.

## 5. 측정하지 않은 항목

- **Raspberry Pi 5의 전력** — 내장 센서 없음, 외부 계측기 미확보
- **정확도** — mAP, 깊이 오차 등 정확도 지표는 측정 범위에 포함하지 않았다
- **동일 정밀도 조건 비교** — Xavier의 INT8 측정은 캘리브레이션 데이터셋이 필요하여 수행하지 않았다
- **DX-M1의 지연 백분위수** — 도구가 제공하지 않는다
- **열 조건 통제** — 주변 온도와 방열 조건을 기록하지 않았다. 장시간 실행 시 스로틀링 영향을 배제할 수 없다
