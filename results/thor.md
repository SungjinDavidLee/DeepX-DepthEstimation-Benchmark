## 4. FP16 대 INT8

| 모델 | FP16 | INT8 | 변화 |
|---|---|---|---|
| yolov8n | 0.854 ms | 1.017 ms | 19% 증가 |
| yolov8n-seg | 0.940 ms | 1.203 ms | 28% 증가 |
| FastSam-S | 1.237 ms | 1.387 ms | 12% 증가 |
| DAv2 ViT-S | 1.214 ms | 1.088 ms | 10% 감소 |
| DAv2 ViT-B | 1.999 ms | 1.712 ms | 14% 감소 |

Convolution 위주 모델에서 INT8이 오히려 느리다. 전력은 모든 모델에서 INT8이 낮다.

## 5. 재현성

FP16을 두 차례 측정했다.

| 모델 | 1차 (2000회) | 2차 (5000회) | 차이 |
|---|---|---|---|
| yolov8n | 0.848 ms | 0.854 ms | 0.7% |
| yolov8n-seg | 0.928 ms | 0.940 ms | 1.3% |
| FastSam-S | 1.223 ms | 1.237 ms | 1.2% |
| DAv2 ViT-S | 1.161 ms | 1.214 ms | 4.6% |
| DAv2 ViT-B | 2.007 ms | 1.999 ms | 0.4% |

1차 측정의 전력 표본은 18~24개(약 4초)로 램프업 구간이 포함되었을 가능성이 있다. 2차는 26~54개다. 본 문서의 값은 2차 기준이다.

1차 전력 측정값은 yolov8n 55.03 W, yolov8n-seg 66.21 W, FastSam-S 80.60 W, ViT-S 58.99 W, ViT-B 78.58 W다.

## 6. 빌드

전체 엔진 빌드 소요 시간은 FP16 약 16분, INT8 약 10분이다. 입력 바인딩은 전 모델에서 의도한 해상도로 확인되었다.

```
yolov8n       1x3x640x640
yolov8n-seg   1x3x640x640
FastSam-S     1x3x640x640
DAv2 ViT-S    1x3x224x224
DAv2 ViT-B    1x3x224x224
```

## 7. 측정하지 않은 항목

- 다른 전력 모드(MAXN, 90W, 70W)에서의 측정
- INT8 캘리브레이션 적용
- 정확도
- 열 조건 통제
